# cut-prompter：短いカットの画像プロンプトと動画プロンプトを作る

このスキルは**プロンプトの文章を書くだけ**です。画像や動画の生成、ファイルの送信はしません。
出力するのは、画像プロンプト（開始フレーム・終了フレーム）と動画プロンプトだけです。

## 進め方

1. **希望と資料を読む**
   - ユーザーの希望（何が起きるカットか・雰囲気・長さ・画面の形）を読み取ります。
   - キャラクターやシーンの資料（設定の文・立ち絵・場所の写真や絵・前後のカットの絵）が渡されたら、全部見ます。画像は開いて自分の目で見ます。
   - 資料の読み方は `reference/references.md`。

2. **足りないことだけ、1 回にまとめて聞く**（わかっていることは聞かない）
   - カットの長さ（2〜10 秒。指定が無ければ内容から決めて、出力の頭に書く）
   - 絵の渡し方：**開始フレーム**／**終了フレーム**／**開始と終了の両方**／**画像なし**（迷ったら開始フレームだけ。選び方は `reference/frame-modes.md`）
   - 使う動画モデルの種類：ふつう（絵と文から動く）か、**声から口パクを作るモデル**か（声の音声ファイルを一緒に渡すもの）
   - 画面の形（横長・縦長・正方形）と画風（アニメ・実写風・3DCG など。資料からわかれば聞かない）
   - ユーザーが「おまかせ」と言ったら、聞かずに決めて、決めたことを出力の頭に 1〜3 行で書きます。
   - 決まっていないときの既定：横長は 16:9、縦長は 9:16。画像生成が分からなければ画像プロンプトも英語。モデルの指定が無ければ「ふつうのモデル」として書き、`reference/model-notes.md` の特定のモデルの注意（コマ数など）は、そのモデルを使うと分かったときだけ反映します。
   - 資料が無い人物の見た目（年齢・服・持ち物）は、希望に合わせて自由に決めて構いません。決めたことは頭のコメントにまとめて書きます（3 行をこえてもよい）。

3. **場面を組み立てる**
   - 誰が・どこで・何をして・どう終わるか、を 1 カットの中で決めます。2〜10 秒で見せられる量にしぼります（1 カット 1 つの動き・1 つの感情の変化が目安）。
   - 10 秒をこえる内容なら、カットを分けることを提案し、分けたそれぞれを書きます。

4. **プロンプトを書く**
   - 画像プロンプト：`reference/image-prompt.md`
   - 動画プロンプト（ふつうのモデル）：`reference/video-prompt.md`
   - 動画プロンプト（口パクのモデル）：`reference/lipsync.md`
   - モデルごとの注意（わかっているもの）：`reference/model-notes.md`

5. **出力する**（下の形だけ。説明・前置き・感想は書かない）

## 出力の形

````markdown
<!-- 長さ 4.0 秒・開始フレームのみ・横長 16:9・ふつうのモデル -->

## 画像プロンプト（開始フレーム）
```
（開始フレームの画像プロンプト）
```

## 画像プロンプト（終了フレーム）
```
（終了フレームの画像プロンプト。使わない渡し方なら、この見出しごと書かない）
```

## 動画プロンプト
```
（動画プロンプト）
```
````

- 1 行目のコメントに、長さ・絵の渡し方・画面の形・モデルの種類を書きます（ユーザーが決めたことと、こちらで決めたことの両方）。
- 「画像なし」なら画像プロンプトの見出しを書かず、動画プロンプトだけにします。
- 口パクのモデルでは、終了フレームは書きません（そのモデルは終了フレームを使わないことが多いため。`reference/lipsync.md`）。
- 複数カットなら、カットごとに `# カット 1`・`# カット 2` … の見出しで同じ形をくり返します。
- ユーザーがプロンプトの言葉を指定しなければ、動画プロンプトは英語で書きます（多くの動画モデルで通りがよいため）。画像プロンプトはユーザーの言葉か英語の、ユーザーが使う画像生成に合う方で書きます。

## 守ること

- **資料の人物を変えない**：資料があるキャラは、顔・髪型・髪の色・目の色・体つき・服・持ち物を、資料のとおりに具体的な言葉で書きます（「資料のとおり」だけで済ませない。動画モデルは資料を見られないことが多いため）。
- **開始フレームと動画プロンプトを食い違わせない**：開始フレームに描くもの（人数・位置・向き・持ち物・光）と、動画プロンプトの「最初の状態」を同じにします。終了フレームも同じです。
- **手・指・向きを言い切る**：手の数・どちらの手で何を持つか・指の本数（5 本）・顔と体の向き・視線を書きます。崩れやすいところだからです。
- **短いカットに収める**：2〜10 秒で起きる量だけを書きます。時刻はカットの頭からの秒で書きます。
- **出力はプロンプトだけ**：生成・送信・ファイルの保存はしません（ユーザーに頼まれたら別にやります）。
